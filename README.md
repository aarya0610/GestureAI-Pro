# 🤖 Gesture AI Pro

An AI-powered Hand Gesture Control System built using Python, OpenCV, and MediaPipe. This project allows users to control their computer with hand gestures in real time.

---

## 🚀 Features

- 🖱️ Virtual Mouse Control
- 👆 Left Click
- 👉 Right Click
- 👆👆 Double Click
- ✋ Drag & Drop
- 📜 Scroll Up / Down
- 🔊 Volume Control
- 💡 Brightness Control
- 🎵 Media Controls
  - Play / Pause
  - Next Track
  - Previous Track
- 🌐 Website Launcher
  - Google
  - YouTube
  - ChatGPT
  - GitHub
  - LinkedIn
- 💻 Application Launcher
  - Calculator
  - Notepad
  - File Explorer
  - Paint
- 📸 Screenshot Capture
- 📊 Live FPS Counter
- 🟢 Professional HUD

---

## 🛠️ Technologies Used

- Python
- OpenCV
- MediaPipe
- NumPy
- PyAutoGUI
- PyCAW
- screen-brightness-control

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/aarya0610/GestureAI-Pro.git
```

Go to the project folder:

```bash
cd GestureAI-Pro
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python main.py
```
